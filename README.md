# 🎮 TRIO.EXE | 8-Bit Arcade Portfolio

Welcome to **TRIO.EXE**! This project is a highly creative, responsive team portfolio website styled with a 1980s retro gaming / arcade machine aesthetic. It was custom-built from scratch for the **Navjeevan Education Society's College of Engineering Hackathon 2026**.

*   **P2: ANKIT** | Class: `Layout Sage` 💻 - Master of semantic structure nodes and core layout configurations.
*   **P3: VRUSHABH** | Class: `Interaction Specialist` ⚡ - Focuses on custom transitions, animations, and fluid sizing.

## 🚀 Key Features
*   **Zero Templates:** Built using clean, pure HTML5 structural nodes and custom CSS variables without copying generic Bootstrap clone scripts.
*   **Stage-by-Step Level Navigation:** Leverages native HTML link anchors coupled with smooth scrolling behaviors (`scroll-behavior: smooth`) to transition between content blocks like gaming levels.
*   **Full 2D Pixel Styling:** Features solid offset drop-shadow card structures (`box-shadow`), neon cyber palettes, and retro typography mapping.
*   **Mobile Ready (100% Responsive):** Uses adaptive layout grids (`grid-template-columns: repeat(auto-fit, ...)`) to ensure the arcade layout folds flawlessly across desktop screens and mobile phones.

## 📂 Web Stage Roadmap (Core Sections)
1.  **Hero Title:** The main intro loader screen displaying the main operational title and interactive launch triggers.
2.  **Character Selection (Team):** Interactive player profiles mapping team metrics and skill disciplines.
3.  **Stage Selection (Projects):** Showcases two foundational project slots detailing web experiments.
4.  **Mission Brief (About):** Sets up our squad identity objectives.
5.  **Inventory Slots (Skills):** Visual grid tags sorting technology power-ups.
6.  **Insert Coin (Contact):** A fully structured transmission panel workspace for message logging.

## 🛠️ Built With
*   **HTML5** - Structure and layout boundaries
*   **CSS3** - Custom properties, grid modules, animations, and responsive breakpoints
*   **Google Fonts** - *Press Start 2P* and *VT323* rendering scripts

## 📐 How to Run the System Locally
1. Clone or download this repository folder onto your machine.
2. Open the folder workspace.
3. Double-click the `index.html` file to boot up the system directly inside any standard modern web browser.
